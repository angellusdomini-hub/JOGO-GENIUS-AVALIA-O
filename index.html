01 · Conheça o projeto

Você vai construir um jogo de memória que une um circuito real a uma interface digital. Observe as cores no LED, espere o sinal SUA VEZ e clique nas bolas na ordem correta. A cada sequência completa, ganhe 10 pontos e memorize uma cor a mais.

Rodada: 3 Pontuação: 20

Referência de organização do palco, com as fantasias do projeto original.

3 s cada cor
1 s LED apagado
10 pontos por rodada

02 · Monte o circuito

Separe 1 Arduino Uno, 1 LED RGB de cátodo comum, 3 resistores de 220 Ω (ou 330 Ω), 1 protoboard, 4 jumpers macho-macho e 1 cabo USB de dados.

  1. Desconecte o Arduino do USB.
  2. Insira os quatro terminais do LED em trilhas distintas da protoboard.
  3. Ligue o terminal comum ao GND.
  4. Ligue cada terminal de cor ao pino indicado, com um resistor em série para cada canal.
CanalLigação
Vermelho (R)D3 → resistor → R
Verde (G)D5 → resistor → G
Azul (B)D6 → resistor → B
Cátodo comumGND → comum
Confira a pinagem do LED com o professor: a ordem física dos terminais varia. Este tutorial usa cátodo comum; não ligue um LED sem resistores.

03 · Conecte o mBlock

  1. Abra o mBlock 5 e crie um projeto novo.
  2. Em Dispositivos → Adicionar, escolha Arduino Uno.
  3. Conecte a placa pelo cabo USB, clique em Conectar e selecione a porta correta.
  4. Escolha Ao Vivo (Live), não Upload.
  5. Salve o projeto com seu nome. Mantenha o USB conectado durante o jogo.
Os desenhos de blocos neste tutorial são representações didáticas. Arraste os blocos das categorias de cores correspondentes; não copie como código textual.

Use a biblioteca para os botões ou desenhe equivalentes. Start e jogar novamente ficam na mesma posição, mas nunca devem aparecer juntos.

Crie o ator Sinalizador com Pintar

  1. Na aba Atores, escolha Pintar para criar um ator vazio.
  2. Renomeie o ator para Sinalizador.
  3. Em Fantasias, selecione a ferramenta Retângulo. Desenhe um retângulo, aplique a cor de preenchimento e acrescente o texto com a ferramenta Texto.
  4. Duplique a primeira fantasia três vezes; altere a cor, o texto e o nome de cada cópia. Mantenha o mesmo tamanho e alinhamento.
  5. Defina tamanho 80%, X = 46, Y = 96 (ajuste se necessário para não sobrepor as bolas).
OBSERVAR
JOGAR
ACERTOU
ERROU

Use amarelo para OBSERVAR (texto ATENÇÃO), verde para JOGAR (SUA VEZ), azul para ACERTOU (PARABÉNS) e vermelho para ERROU (FIM DE JOGO). Os exemplos acima são as fantasias do projeto original.

Selecione Start → Variáveis → Criar uma variável. Marque Para todos os atores em cada uma. Em Criar uma lista, crie Sequência também para todos os atores.

Exemplo: a lista [2, 3, 1] guarda verde, azul e vermelho. A posição começa em 1. A cada rodada, um número novo é acrescentado à lista, sem apagar os anteriores.

11 · Teste e entregue

Clique na bandeira verde, depois em Start. Teste o projeto com o Arduino conectado. Confira cada comportamento antes de entregar.

ProblemaConfira

Sequência não cresceAdicionar número aleatório à lista, sem apagar nas rodadas.
